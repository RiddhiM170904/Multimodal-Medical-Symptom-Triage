Multi-Layer Data Routing

Our architecture distributes features to custom-trained ML models. For visual indicators (like skin lesions, rashes, or suspicious moles), **EfficientNetB0** performs transfer learning classification across the HAM10000 and general skin disease datasets.

Simultaneously, natural language symptom entries are analyzed in parallel: **DistilBERT** classifies unstructured narratives (e.g. *Symptom2Disease*) while a **Random Forest** parses binary symptom flags.

Outputs feed into **XGBoost** alongside vital statistics (SpO2, heart rate, temperature) to calculate a clinical severity metric.

Severity Gating & GenAI Safety

A strict severity gating rule protects users: if XGBoost grades a patient case with severe features (e.g. high-fever sepsis risk or low SpO2), a high-priority emergency path activates immediately, flagging critical medical emergency warnings to consult immediate professional care.

If severity is mild/moderate, **Claude 3.5 Haiku** generates structured suggestions, explaining which clinical paths apply, using prompt engineering to enforce medical boundaries (reaffirming that this tool is decision-support only and not a definitive diagnosis).

Phase 2: Training the ML Classification Layer

Here, we train the models across our three data layers. The image models leverage transfer learning with an EfficientNet-B0 backbone, employing PyTorch with cross-entropy class-weighted loss to address the severe imbalances in HAM10000.

Model Training Snippets 
# Define EfficientNetB0 Transfer Learning Model for Skin Lesion Classification
import torch.nn as nn
from torchvision import models

class LesionClassifier(nn.Module):
    def __init__(self, num_classes=7):
        super(LesionClassifier, self).__init__()
        # Load pre-trained EfficientNetB0
        self.backbone = models.efficientnet_b0(pretrained=True)
        # Freeze initial layers to retain low-level image features
        for param in list(self.backbone.parameters())[:-20]:
            param.requires_grad = False
            
        # Replace classifier head with clinical dropout & linear layer
        in_features = self.backbone.classifier[1].in_features
        self.backbone.classifier = nn.Sequential(
            nn.Dropout(p=0.4, inplace=True),
            nn.Linear(in_features, num_classes)
        )
        
    def forward(self, x):
        return self.backbone(x)
